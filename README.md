1. Proyecto en Angular

Este es un proyecto desarrollado con **Angular 17**.

 Requisitos previos

2. Asegúrate de tener instalados en tu sistema:

- [Node.js](https://nodejs.org/) (versión recomendada: LTS)
- [Angular CLI](https://angular.dev/cli)  

3. Verifica que tienes Angular CLI instalado:

```bash
ng version

4. Si no lo tienes, instálalo con 
npm install -g @angular/cli



5. Clona el repositorio y entra en la carpeta del proyecto:

git clone <url-del-repositorio>
cd <nombre-del-proyecto>


6. Instala todas las dependencias:
npm install



7. Para iniciar el servidor de desarrollo, ejecuta:
ng serve -o
